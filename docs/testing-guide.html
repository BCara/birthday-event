Memory Capsule

The Memory Capsule is a private collection — guests submit photos and messages but never see anyone else's, and only the host can view them. There is no public memory wall and no live slideshow.
Pre-conditions: the capsule must be enabled on the event (8.1), and the privacy checks in 8.5 require the latest firestore.rules / storage.rules to be deployed.
