# Future Features & Growth Ideas (Category C)

This document tracks high-impact features for future development.

## 1. Advanced WhatsApp Integration
- Allow hosts to send reminders directly through a managed WhatsApp API.
- Eliminate dependency on the host's local device/client.
- Automated "Party Starting Soon" and "RSVP Deadline" messages.

## 2. Printable QR Assets
- Generate high-quality PDF "Welcome Signs" or "Table Cards".
- Automatically brand assets with the selected party theme and mascot.
- Include the party's unique QR code.

## 3. Host Calendar Sync
- Automatically send an .ics or Google Calendar invite to the host's email upon event creation.
- Ensure the event is blocked out in the host's personal calendar with a link to the dashboard.

## 4. Image Optimization
- Implement cloud-side image resizing (e.g., via Firebase Extensions) to ensure mobile-friendly page weights.
